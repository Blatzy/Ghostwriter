How to Use

Built-in types have dynamic generation logic (e.g., finding creates one slide per finding). Custom slides are static layouts with Jinja2 variable support. You can change the type of any slide directly via the Type column in the table below.

Built-in Slide Types:

TypeDescription
titleTitle/cover slide for the presentation
agendaAgenda or table of contents slide
introductionTeam introduction slide listing assessors
assessment_detailsOverview of the assessment scope and objectives
methodologyDescription of the methodology used
timelineAssessment timeline and key dates
attack_pathAttack path overview diagram/description
observations_overviewSummary table of positive observations
observationOne slide generated per observation (dynamic)
findings_overviewSummary table of all findings by severity
findingOne slide generated per finding (dynamic)
recommendationsConsolidated recommendations slide
next_stepsNext steps and remediation roadmap
finalClosing/thank-you slide

Jinja2 Variables for Finding Slides:

  • {% verbatim %}{{ title }}, {{ severity }}, {{ description }}{% endverbatim %}
  • {% verbatim %}{{ impact }}, {{ mitigation }}, {{ affected_entities }}{% endverbatim %}
  • {% verbatim %}{{ replication }}, {{ references }}, {{ cvss_score }}{% endverbatim %}

Jinja2 Variables for Static/Custom Slides:

  • {% verbatim %}{{ client.name }}, {{ project.codename }}, {{ project.start_date }}, {{ project.end_date }}{% endverbatim %}
  • {% verbatim %}{{ report.title }}, {{ company.name }}, {{ now }}{% endverbatim %}
